Step 1

You ask Claude Code something.

❯ why does the login test fail?

Step 2

The answer starts with one short line.

❯ why does the login test fail?
TL;DR: It used an old password. Fixed, and it passes.

Step 3

A voice reads that line aloud.

It starts about a second after the line appears, while the rest of the answer is still printing. Only that line is read.

Online voice by default. If it is slow or offline, a local voice takes over.

Want to reply?

Just start. The voice stops.

Type your next message→it goes quiet
Hold space to talk→it goes quiet

You stay in charge

Click 🔊 above the prompt to mute.

/tldr-voice:voice off | onmute or unmute
/tldr-voice:voice language deGerman (or en)
/tldr-voice:voice engine piperoffline voice only
/tldr-voice:voice testhear the voice

TL;DR Voice

Claude Code reads its summary line to you.

A Claude Code plugin · English or German · Linux · free and open source

Claude Code starts every answer with a one-line TL;DR, and a voice reads that line aloud while the rest is still printing. Typing or holding space stops it.

Try it

/plugin install tldr-voice --marketplace d-shiri/tldr-voice

In Claude Code, on Linux with Python 3 and mpv. Free, open source, no API keys. Source, docs and uninstall instructions: github.com/d-shiri/tldr-voice
