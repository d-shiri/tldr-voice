TL;DR Voice

Your terminal, read aloud.

Claude Code hooks · neural voice · offline backup · built in one afternoon

A home-made add-on for the Claude Code terminal: every answer opens with a one-line summary, and a voice reads it to you while the rest is still printing. Hooks plus a small background helper, with a local voice as backup.

Try it

git clone https://github.com/d-shiri/tldr-voice.git
cd tldr-voice && ./install.sh

Linux, Claude Code, Python 3 and mpv. Free, open source, no API keys. Source, docs and uninstall instructions: github.com/d-shiri/tldr-voice
